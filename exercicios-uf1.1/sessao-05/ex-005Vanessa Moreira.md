### Missão 3: O Relatório

Respondam às seguintes questões com as vossas próprias palavras:

1. Segurança e navegação:
   Para que serve o atributo `target="_blank"` e porque é fundamental acrescentar `rel="noreferrer noopener"` sempre que abrimos um link num novo separador?
   Resposta: [O target="_blank" serve para abrir um link num novo separador, sem sair da página onde estamos. O real="noreferrer noopener" é importante porque ajuda a proteger a nossa página, evitando que o site que abrimos tenha acesso a algumas informações da página original.]

2. Escolha de listas:
   Qual é a diferença funcional entre uma lista `<ul>` e uma lista `<ol>`? Deem um exemplo prático de um tipo de conteúdo para cada uma.
   Resposta: [A diferença entre <ul> e <ol> é que a <ul> apresenta os elementos com pontos, sem precisar de uma ordem específica, enquanto a <ol> apresenta os elementos numerados, seguindo uma sequência. Por exemplo, podemos usar <ul> para fazer uma lista de materiais necessários para uma viagem e <ol> para organizar os passos de uma receita.]

3. Tabelas e semântica:
   Porque é proibido em HTML moderno utilizar o elemento `<table>` para definir a disposição visual (layout) de uma página? Qual é o único objetivo legítimo de uma tabela?
   Resposta: [Porque não devemos utilizar o elemento <table> para organizar o visual de uma página porque as tabelas servem para apresentar informações e dados organizados em linhas e colunas e não para construir o layout de um site, para isso usamos o CSS. O objetivo de uma <table> é apresentar dados de forma organizada, através de linhas e colunas.]
